МОЯ ŠKODA | Telegram Mini App

Это адаптация вашего загруженного HTML-приложения, не новый пустой шаблон.

ЗАПУСК В TELEGRAM:
1. Создайте бота в Telegram через @BotFather, команда /newbot. Сохраните токен в секрете.
2. Разместите index.html, manifest.webmanifest, icon-192.png и icon-512.png в одной папке на HTTPS-хостинге (например, GitHub Pages).
3. В @BotFather выберите бота и настройте Menu Button (/setmenubutton), указав HTTPS-адрес index.html. При необходимости настройте Main App через BotFather.
4. Откройте чат с ботом, нажмите кнопку меню для запуска приложения.

ОГРАНИЧЕНИЯ:
- Telegram WebApp SDK активен только при открытии внутри Telegram.
- Данные сохраняются в localStorage текущего браузерного окружения. Safari и Telegram имеют разные хранилища.
- Вверху справа кнопка «Данные» экспортирует и импортирует JSON. Импортируйте только свои резервные копии.
- Автоматической облачной синхронизации нет. Для нее нужен сервер и безопасная проверка Telegram initData.
- Не публикуйте токен бота в HTML или репозитории.
- Внешние функции исходного приложения могут требовать сеть или дополнительные разрешения.
